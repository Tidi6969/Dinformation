Dinformation V17 shared multi-host runtime.
Load only the matching DLL for the active CAD host:
  AutoCAD 2022  = DinformationC22.dll
  AutoCAD 2025  = DinformationC25.dll
  GstarCAD 2018 = DinformationG18.dll
  GstarCAD 2027 = DinformationG27.dll
Command: DINFORMATION
AutoCAD 2022/2025 and GstarCAD 2027 use LISP recognition/data reading with the existing native tooltip display.
Reference SDK DLLs are build-only and are NOT copied to Dprogram.
